## Opening a page from a OneStream Workflow Profile

One part of this is already documented. A Revfore [Content Item](../../concepts/metadataDrivenUI/contentItem.md) dashboard configured in [Genesis](../genesis/index.md) can be opened directly from a **OneStream workflow profile** input step, so the page is reached through the workflow rather than through navigation.

See [Linking a Workflow Profile form to a Revfore Content Item dashboard](../../appGroups/admin/workflow/index.md#linking-a-workflow-profile-form-to-a-revfore-content-item-dashboard).
